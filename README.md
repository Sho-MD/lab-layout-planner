# 研究室 レイアウト検討ツール

**55.3㎡** の研究室について、什器レイアウトをブラウザ上で比較・編集するための単体HTMLツールです。
ビルド不要・依存ライブラリなし。`index.html` を開くだけで動作します。

**公開URL:** https://sho-md.github.io/lab-layout-planner/

---

## できること

### レイアウトパターン 6案の切替

| # | パターン | 席数 | 特徴 |
|---|---|---|---|
| ① | 島2つ | 執務8 / 会議8 | 4席島×2。北=執務、南=カンファをパーティションで分離 |
| ② | 島1つ | 執務8 / 会議8 | 中央に6席の大島＋窓側2席。給湯棚を流し台の隣へ |
| ③ | 全席壁向き | 執務8 / 会議8 | 机を全部壁に向け、中央を空けて会議テーブル |
| ④ | コの字 | 執務8 / 会議8 | 全員が中央を向き、その場でカンファ可能 |
| ⑤ | 会議重視 | 執務4 / 会議12 | 4,000×1,200の大テーブルに12席 |
| ⑥ | ブース型 | 執務8 / 会議6 | 壁沿いに1人用ブース、間をH1,100で仕切る |

### 室の内法（面積55.3㎡ 固定）

幅 W を入力すると奥行 D が `55,300,000 ÷ W` で自動計算されます（D から W の逆算も可）。
窓・出入口2か所・既設排水口4か所の位置も内法に比例して追従します。既定は 7,245 × 7,633 mm。

### 什器の編集

- ドラッグで移動（25mmスナップ）、矢印キーで50mm移動（Shiftで10mm）
- 選択すると四隅・四辺に□ハンドル。辺＝縦/横、角＝斜めにサイズ変更（回転済みの什器にも対応）
- 名称・種類・W/D/H・塗り/線の色を自由に変更、自由入力での新規追加
- **基準寸法から変えると名前が自動で「机」→「机A」に分岐**し、元の寸法に戻すと「机」へ復帰
- 90°回転 / 複製 / 削除 / 重なり順の変更

### 出力

- 縮尺 1/40・1/50（A3横）、1/60（A4横）で印刷・PDF化
- PNG / SVG / JSON 書き出し、JSON読込、ブラウザ保存（localStorage）

## 図面の読み方

- グリッドの細線 = **500mm**、やや濃い線 = 1,000mm
- 赤い破線の扇形 = 出入口の開閉範囲（内開きと仮定）
- ◎印 = 既設排水口（塗りつぶし＝流し台で使用する位置）
- フリーザー周囲の赤破線 = 壁から100mm以上の離隔帯

---

## 検証済み事項

6パターンすべてについて、以下を自動チェック済みです。

- **干渉**: 室外はみ出し / 什器どうしの重なり / 扉の開閉範囲 / フリーザーの壁離隔100mm → 全パターン0件
- **動線**: 50mmグリッドのフラッドフィルで、幅550mmの人が出入口から全席に到達できること → 全席OK

---

## 注意

- 面積 55.3㎡ は確定値ですが、**内法の縦横比は 55.3㎡ ÷ 7,245mm からの逆算値**です。実施設計図で確定したら「室の内法」欄に入力してください。
- 低温フリーザー UD-80W74NF（74L / W640×D490×H950 / 70kg / 単相100V 7.6A）は、**専用回路コンセント1口**・壁から100mm以上の離隔・上開きのため上方と前面の開閉スペースが必要です。
